## Périmètre

Ce fichier s'applique uniquement au site `bhorville-it.fr`.

Il ne s'applique pas à :
- `horville-labs`
- `onpremsoftware.com`
- `onpremsoftware.fr`

Les règles générales du dépôt racine restent applicables.

### Gestion de configuration

Toute information configurable (nom, domaine, URL, email, liens, états de projets) doit être centralisée dans le fichier de configuration (`config/site.js` ou équivalent) plutôt que durcie dans le code HTML/CSS/JS. Cette pratique facilite les maintenances et évite les incohérences entre les différents fichiers de présentation.

---

## Identité

`bhorville-it.fr` correspond à l'identité professionnelle personnelle de Bernard Horville.

Ne pas transformer `bhorville-it.fr` en site commercial OnPrem Software.

---

## Positionnement

`bhorville-it.fr` présente :
- mon parcours ;
- mes compétences ;
- mon expérience ;
- mes domaines d'intervention ;
- mes réalisations ;
- mes coordonnées professionnelles.

Un lien vers `onpremsoftware.com` peut exister lorsqu'il est pertinent, notamment pour présenter une réalisation ou un projet, mais il ne doit pas constituer une navigation globale obligatoire.

---

## Règles éditoriales

Ne pas présenter OnPrem Software comme une sous-section de bhorville-it.fr.

Ne pas faire de `onprem-software.com` le centre de la navigation de `bhorville-it.fr`.

Un lien vers OnPrem Software peut éventuellement apparaître lorsqu'il est pertinent dans une présentation de réalisation, d'activité ou de projet, mais il ne doit pas devenir un élément structurant de la navigation.

---

## Règles de navigation

Ne pas ajouter de lien retour vers Horville Labs dans la navigation, le footer ou les pages principales d'OnPrem Software.

---

## Règles SEO spécifiques

Respecter l'identité de bhorville-it.fr sans la mélanger avec OnPrem Software ou Horville Labs.

Éviter notamment les formulations du type :
- "Bernard Horville présente..."
- "Horville Labs, le laboratoire d'OnPrem Software"
- "OnPrem Software, le projet de Horville Labs"

sauf nécessité explicite.
